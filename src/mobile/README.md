# HEIMAT 2.0 — Mobile App

Die erste Open-Source Super App für Deutschland.

## Features

- **Gesundheit**: Ärzte finden, AI-Triage, Lebenszeichen
- **Mobilität**: ÖPNV, Routing, E-Ladestationen
- **Finanzen**: Taler-Zahlung, Budget-Tracker
- **Dashboard**: Wetter, Abfall, Luftqualität

## Technologien

- Flutter 3.x (Dart)
- Provider (State Management)
- flutter_map (Karten)
- Geolocator (GPS)

## Development

```bash
flutter pub get
flutter run
```

## Testing

```bash
flutter test
```
